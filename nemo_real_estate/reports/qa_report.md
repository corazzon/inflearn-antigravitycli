### UX/UI 및 인터랙션 검증
- **스켈레톤 로딩 UI**: 최초 페이지 로드 시 400ms 동안 펄스 이펙트의 스켈레톤 로더 노출로 로딩 불안감 해소.
- **실시간 필터 칩(Badge)**: 적용된 필터(지하철역, 보증금 범위, 월세 범위 등)가 실시간으로 상단 칩으로 표현되며, 칩 내 'X' 클릭 시 개별 초기화 동작 확인.
- **숫자 카운트업 애니메이션**: KPI 카드 로딩 시 수치가 0부터 최종값까지 부드럽게 증가.
- **Empty State UI**: 검색 결과가 0건일 때, 테이블이 사라지고 일러스트와 팁이 포함된 안내 영역이 표시됨.
- **단축키(ESC) 연동**: 매물 상세정보 팝업 모달창이 ESC 키를 입력했을 때 자연스럽게 닫혀 키보드 접근성 확보.
- **다크/라이트 테마**: CSS 변수 시스템을 기반으로 한 테마 토글 버튼이 매끄럽게 작동하며, 차트의 텍스트 및 그리드 색상도 테마에 연동되어 가독성 유지.
- **금액 한글 포맷팅**: `formatMoney()` 함수를 통해 "5억 5,000만원", "350만원" 등으로 직관적인 원화 표기 제공.
